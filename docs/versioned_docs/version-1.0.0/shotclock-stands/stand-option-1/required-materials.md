## 🧰 Required Materials

DSS reccomends you get your components at either **Lowe's** or **Home Depot**. All of these parts can be gotten in one quick trip to your local store.

Below is a breakdown with convenient links to popular retailers for these components:

**Print Settings (Bambu Studio)**
- Generic TPU profile
- 0.4mm nozzle
- 0.28mm layer height
- 5% infill
- Triangles infill pattern

**Print Settings (Cura)**
- 0.4mm nozzle
- 0.28mm layer height
- 5% infill
- Triangles infill pattern
- No support
- Nozzle temp 240 oC
- Heat bed: 35 oC
- 2 walls
- Print speed: 15-30 mm/s
- Retraction Distance: 1.0-2.0 mm
- Retraction Speed: 15-20 mm/s

:::note
No printer? Try a local makerspace or order online from [JLCPCB](https://jlcpcb.com/), [Xometry](https://www.xometry.com/), or similar services.
:::
