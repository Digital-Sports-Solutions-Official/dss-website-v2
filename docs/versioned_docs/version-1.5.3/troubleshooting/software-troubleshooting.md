## 🖥 Software Troubleshooting

If you're experiencing issues with the **tinyLeague™ Hub**, or any of the tinyLeague™ software, start here. Below are answers to the most common software questions and concerns.

---

> ### "The shot clock keeps resetting when I un-pause"

- To bring your shotclock out of the un-paused state you have 2 options:
    - Using the reset button (center of the screen) will unpause AND reset the clock
    - Using the unpause button (bottom right of the screen) will unpause the clock BUT keep decrementing the number the clock was paused at
---

> ### "My shot clock keeps resetting to the wrong number"

- Ensure that you have your desired high/low times set in the settings page
- Ensure that the High/Low switch is set the to appropriate state that you desire

---

> ### "I forgot my pin for the settings page"

- For security reasons, the pin for the settings page is not recoverable. To reset your application, you will need to uninstall and reinstall the app on your Android smart device. This will reset the apps pin preferences, allowing the user to reaccess the settings.

---

>### "When I press undo, the clock doesn't seem to be correct"

- The tinyLeague™ Hub app has the option for "true-undo", this will impact the undo function
    - If toggled ON, then the shotclock will return to the previous value SUBTRACTING the time elapsed from the previous reset
    - If toggled OFF, then the shotclock will resume counting from the previous value, before the last reset
