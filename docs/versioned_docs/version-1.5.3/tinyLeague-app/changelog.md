What's new in each release of the **tinyLeague™ Hub** app. [Check which version you're running](/docs/tinyLeague-app/app-installation#-check-your-app-version).

## Releases

### **v1.5.3** – *June 2026* `latest`

#### What's New

- Connected shot clocks keep counting while the app is minimized
- Android shows a notification while a shot clock is connected
- Four new colors for your shot clock display

#### Improvements

- Color picker fits tablets and larger screens
- Buzzer no longer sounds early when you reopen the app
- No beeps or vibrations while the app is minimized
- The + button grays out at 99 seconds

### **v1.5.2** – *May 2026*

#### What's New

- Live Adjustment is now on by default
- Your screen stays on while the app is open

#### Improvements

- Smoother countdown in the final five seconds
- Beeps and vibrations stay in sync
- Timer stays accurate when you return to the app
- Fixed crashes and slowdowns during long games

### **v1.5.1** – *April 2026*

#### What's New

- Live Adjustment: use -/+ while the timer is running
- Connect to a computer for livestreaming (beta)
- Cleaner, reorganized settings and device screens
- See your app version at the bottom of Settings

#### Improvements

- Adjusted time is kept when you unpause
- Reset instantly stops the buzzer and vibration
- Countdown beeps match the clock and no longer overlap
- Faster shot clock discovery and pairing
- Messages show device names instead of ID numbers
- Saved devices stay saved after closing the app
- Light and dark mode display fixes

### **v1.4.3** – *July 2025*

#### What's New

- Supports more Android phones
- Optimization and bug fixes

### **v1.4.2** – *July 2025*

#### What's New

- Corrected versioning issues with app
- Updated cross platform release app bundle for iOS and Android

#### Improvements

- Updated licensing for application

### **v1.4.1** – *July 2025*

#### What's New

- UI Update

#### Improvements

- Replaced Bluetooth icon
- Reworked the available devices scanning

### **v1.4** – *July 2025*

#### What's New

- UI Overhaul
- Device Information menu
- Multi-Device Support
- App theme toggle

#### Improvements

- tinyLeague Hub is now available on iOS and Android!
- Added device connection information and signal indicator
- Multiple devices can now be connected to a single smart device
- App theme can be toggled between Light/Dark modes

### **v1.3** – *April 2025*

#### What's New

- Small fix to allow more support for an increased number of devices.

#### Improvements

- Fixed an issue when trying to connect to module around many BLE services.

### **v1.2** – *March 2025*

#### What's New

- Over-the-air updates to easily update module firmware
- New Bluetooth Capabilities for stronger connections, as well as a new available devices menu
- UI framework overhaul

#### Improvements

- Reduced potential bluetooth standard related crashes
- OTA optimizations for ease of update
- More robust connection to uphold game integrity

### **v1.1** – *February 2025*

#### What's New

- Fixed bluetooth permission settings bug crash
- Fixed bluetooth paired devices menu parallel scroll UI bug

#### Improvements

- Reduced potential bluetooth permissions related crashes
- All settings components are dynamically sized to allow access to the user

### **v1.0** – *February 2025*

#### What's New

- Robust shot-clocking application for use with tinyLeague™ shot clock modules, or for practice!

#### Improvements

- New functionality to customize how your shotclock looks and operates, including high/low timer limits, color selection, sound controls, and more.
