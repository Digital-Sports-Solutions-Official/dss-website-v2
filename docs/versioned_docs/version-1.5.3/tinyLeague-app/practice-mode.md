## 🏋️‍♂️ Practice Mode Overview

Practice Mode is a flexible state that allows you to use the tinyLeague™ Hub app **without connecting to a shot clock module**. This is ideal for solo testing, referee training, or team practice when a physical display isn't around.

---

### 🚫 No Module Connection

Practice Mode activates automatically when no module is connected. You'll still see all standard features:

- Timer functionality
- High/Low time switch
- Reset, Unpause, and Undo buttons

While you are able to access the entire settings menu, you will find that the **Devices Settings** menu, rename module, and color controls settings are disabled.

---

### 🧠 Why Use Practice Mode?

:::tip Use Case
Practice Mode is perfect for training referees, testing timing flows, or running internal scrimmages without needing to setup any display modules.
:::

---

### ✅ What Works in Practice Mode

| Feature              | Works in Practice Mode? |
| -------------------- | ----------------------- |
| Timer Controls       | ✅ Yes                  |
| Device Settings Menu | ❌ No                   |
| App Settings Menu    | ✅ Yes                  |
| Device Connection    | ❌ Not Available        |
| True Undo            | ✅ Yes                  |
| Sound & Visual Cues  | ✅ Yes (on phone only)  |

---

### 🔄 Switching Back

To exit Practice Mode, simply connect to a shot clock module via **Connections Menu → Available/Saved Devices**.

Once connected, all commands and visuals will be synced with your external display unit in real-time.
